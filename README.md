# Ali Traders Wedding Suit Rental System

Ali Traders Wedding Suit Rental System is a full-stack application developed to manage wedding suit rentals and customer orders.

The system consists of a PHP and MySQL-based customer website and a Java Swing-based administration application. Customers can browse wedding attire by category, create accounts, log in, manage a shopping cart, and submit their order and delivery information. Administrators can manage product information through a separate desktop application.

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Java
- Java Swing
- JDBC
- NetBeans

## Main Features

- Customer registration and login
- Men's and women's clothing categories
- Kandyan and Western wedding attire
- Product browsing
- Shopping cart
- Customer and delivery information management
- MySQL database integration
- Java Swing administrator login
- Add products
- Update products
- Delete products
- Separate customer and administrator interfaces
